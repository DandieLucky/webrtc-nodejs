Sistem Konferensi Video WebRTC Lokal

Aplikasi streaming video satu arah berbasis Node.js, Socket.IO, dan WebRTC dengan sertifikat HTTPS mandiri serta dukungan transmisi langsung file video dari komputer ke perangkat lain.

🛡️
Penting untuk Akses Pertama Kali: Karena aplikasi menggunakan sertifikat SSL mandiri (Self-Signed), browser komputer maupun HP akan menampilkan peringatan keamanan (misal "Your connection is not private"). Klik tombol Advanced (Lanjutan) lalu klik Proceed (Lanjutkan ke situs).

Panduan Pengujian Praktikum
📋 Panduan 3 Skenario Percobaan & Tugas Video
Siap Diuji

1. Percobaan 1 (1 Komputer Beda Browser)

Menguji WebRTC di komputer yang sama menggunakan dua browser berbeda via localhost.

  1. Buka Chrome, akses https://localhost:8080/broadcaster.html.
  2. Unggah file video lokal dan salin Token Room yang muncul.
  3. Buka Edge / Firefox, akses https://localhost:8080/viewer.html.
  4. Masukkan token lalu klik Join. Video akan tampil di browser kedua.

2. Percobaan 2 (1 Komputer via IP LAN)

Menguji akses melalui alamat IPv4 jaringan LAN pada browser kedua.

  1. Broadcaster tetap dibuka di browser pertama (Chrome).
  2. Buka browser kedua, akses https://[IP_LAN]:8080/viewer.html.
  3. Lewati peringatan SSL (Advanced ➔ Proceed).
  4. Masukkan token untuk memutar video melalui antarmuka IP LAN.

3. Percobaan 3 (Komputer ke HP / Laptop Lain)

Menguji transmisi video antar perangkat di jaringan Wi-Fi yang sama.

  1. Pastikan Komputer dan HP Anda terhubung ke Wi-Fi yang sama.
  2. Di Broadcaster, klik "Salin Link Viewer untuk HP" atau scan QR Code dengan kamera HP.
  3. Buka link di browser HP, lewati peringatan SSL (*Tampilkan Rincian ➔ Kunjungi situs*).
  4. Video akan langsung streaming dari komputer ke HP Anda secara real-time!
